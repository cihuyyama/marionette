# Marionette Admin

**One-liner:** Control room for a Rust AI proxy pool — many Grok (then Qoder) accounts as marionettes, one operator.

**Mode:** Operate (dense admin tool)

**Audience:** Single operator managing account pool health, import, and smoke tests against the local Marionette API.

**Stack:** React + Vite + TypeScript SPA. Dark only. Secrets in localStorage only.
